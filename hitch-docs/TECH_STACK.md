# Technical Stack & UI Specifications

## 1. Core Frameworks
* **Frontend:** Next.js (App Router) for high performance, SEO optimization, and seamless routing.
* **Styling:** Tailwind CSS for fast, responsive, and maintainable styling.
* **UI Components:** Shadcn UI combined with Acernity UI for clean, accessible, and interactive components.

## 2. Visual Identity & Theme
* **Theme Name:** Soft Pop (Custom HSL/OKLCH color variables).
* **Primary Color:** Vibrant Purple/Blue (`oklch(0.5106 0.2301 276.9656)` in light mode) to communicate trust and modernity.
* **Typography:** `DM Sans` (Sans-serif) for all UI elements to ensure maximum legibility and a clean look. `Space Mono` for technical data.
* **UI Geometry:** Generous border radius (`1rem`) on cards and buttons to create a soft, welcoming user experience. Support for both Light and Dark modes.

## 3. Backend & Integrations (Proposed)
* **Database & Auth:** Supabase (PostgreSQL) for scalable relational data and secure authentication.
* **Mapping & Routing:** Google Maps API or Mapbox for address autocomplete, distance calculation, routing, and live driver tracking.
* **Payments:** Stripe integration for handling customer payments and driver payouts.

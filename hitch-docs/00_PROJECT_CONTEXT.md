# Project Context: Hitch (Ride-Booking Platform)

## Project Goal
To build a streamlined, highly efficient ride-booking platform tailored primarily for airport-to-hotel and hotel-to-airport transfers. The system ensures a frictionless booking experience for passengers while providing robust management tools for drivers and administrators.

## Key Constraints & Focus Areas
1. **Clean & Minimalist UI:** The user interface must be fast, distraction-free, and straightforward (inspired by platforms like airporttaxis.com). 
2. **Unified Backend:** The platform consists of three distinct front-end interfaces (Passenger, Driver, Management) that must all communicate with a single, synchronized API/Backend layer.
3. **One-Tap Booking:** The landing page must prioritize speed, offering pre-set trips alongside a custom search widget.
4. **Modern Aesthetics:** The system will utilize the "Soft Pop" theme (vibrant blues, clean backgrounds) with the DM Sans font and rounded components (1rem radius) for a friendly, trustworthy, and modern feel.

## Documentation Structure
1. **CORE_PRD.md:** The MVP features and platform architecture.
2. **TECH_STACK.md:** Technologies and UI frameworks (Next.js, Tailwind, Shadcn).
3. **DATA_ROLES.md:** Database schema, fleet management, and security roles.
4. **WORKFLOW_SRS.md:** The strict 7-step booking flow and system logic.
